## 安全验证

- 源目标相同/包含关系、系统关键路径和版本目录重叠会被拒绝。
- 覆盖、隔离和删除传播必须经过预览与授权，自动任务使用独立安全授权。
- 高风险同步执行实际隔离，不静默永久删除。
- 预览后源变化和计划外目标出现会阻止提交。
- 严格模式使用 SHA-256 判断内容变化；同步快照保存内容哈希并完成数据库往返测试。
- 安装器和卸载器验证目标目录，不允许对磁盘根、用户目录、Windows 根或 Program Files 根执行递归删除。
- 凭据使用 Windows Credential Manager；通知和服务日志会对令牌、密码和 Bearer 头脱敏。

## 外部环境验收项

下列能力已实现和编译，但发布机没有用户的设备、账号或管理员授权，因此未伪造“真实服务连接成功”结论：

- MTP 手机/相机设备。
- FTP/FTPS/SFTP/WebDAV、S3/OSS/COS 和各云盘账号。
- VSS 本地 NTFS 热备份的管理员权限场景。
- Windows Service 写入系统服务控制管理器的安装步骤。

这些项目应在目标环境使用专门测试账号和非生产数据做连接验收；本地文件复制、九种任务模式、备份恢复、调度、数据库、CLI、服务自检和桌面端均已在本机实际验证。
