# CopyTools AI 辅助功能规划

> 基准：1.x（迭代 12 后，126/126 离线回归）。本文规划"AI 能为文件复制/同步/备份工具增加什么"，并给出优先级、落地方式与隐私边界。
> 原则：**AI 是顾问，不是执行者** —— 所有破坏性操作仍走现有"预览 → 风险确认 → 隔离区 → 阈值/竞态检查"闭环；AI 只做建议、解释、摘要与辅助决策，不直接触发删除/覆盖。

## 实现状态（迭代 13）

本文全部 19 项能力已实现并纳入离线回归（150/150 通过，0 警告 0 错误）。落地方式：

- **可插拔抽象**：`IAiAssistant`（Application），三实现 —— `RuleBasedAssistant`（规则降级）、`OllamaAssistant`（本地）、`OpenAiCompatibleAssistant`（云端 OpenAI 兼容），经 `AiAssistantFactory` 按 `ApplicationSettings.AiProvider` 选择；`AiJson` 从 LLM 输出稳健提取 JSON（容忍 Markdown 围栏）。
- **确定性核心 + 可选 LLM**：每个功能服务都有不依赖模型的确定性实现（模板/规则/启发式/统计），仅在配置了可用 `IAiAssistant` 时尝试 LLM 增强，失败自动回退。
- **内容级能力（C1-C4）** 交付的是**扩展名/文件名/大小**等元数据启发式；读取文件内容的语义增强（嵌入/感知哈希/内容分类）按文档原则仍需显式授权与本地模型，未默认接入。

## 0. 设计原则与架构假设

1. **隐私优先，元数据优先**：默认 AI 只读取文件元数据（路径、大小、时间、哈希、错误信息、运行历史），**不读取文件内容**；内容级理解（分类、去重、敏感识别）必须单独授权。
2. **本地优先，可降级**：优先支持本地模型（Ollama/本地推理），云端 API 仅作为可选 provider；无网络、无密钥时功能自动降级为纯规则。
3. **确定性内核不变**：复制、同步、备份、隔离、删除阈值等现有逻辑保持确定性，AI 只作为外围增强层接入，遵循现有插件式扩展风格。
4. **统一抽象**：新增 `IAiAssistant`（Application 层）抽象 provider，实现 `LocalOllamaAssistant` / `CloudApiAssistant` / `NullAssistant`（降级用），与现有 `ICopyToolsPlugin`、存储适配器、校验提供程序同构。

## 1. 功能清单（按类别，带优先级）

优先级：**P0** 高价值+低风险，优先做 · **P1** 重要增强 · **P2** 高级/实验。

### A. 交互与配置（自然语言 → 任务）

#### A1 自然语言任务创建
- **描述**：输入"把 D:\照片 每天镜像到移动硬盘，跳过缓存，改动超过 20% 要我确认"，解析为 `CopyTaskRequest`（源/目标/模式/过滤/删除阈值/计划）。
- **价值**：降低 9 种同步模式 + 复杂过滤规则的上手门槛（这是竞品 FileGee 学习成本高的痛点）。
- **落地**：LLM 输出结构化 JSON → 校验后映射到现有 `CopyTaskRequest`/`TaskSchedule` 字段，非法值回退默认并提示。
- **隐私**：仅元数据/用户输入文本，不读文件内容。**P0**。

#### A2 同步模式智能推荐
- **描述**：根据用户意图（"两个目录保持一致" / "只追加新文件" / "搬家后清空源"）推荐最合适的模式，并说明后果（是否会产生删除）。
- **价值**：镜像/更新/移动/双向等模式的删除语义是最大误操作源，AI 用自然语言把后果讲清楚。
- **落地**：意图分类 + 模式对照表 + 风险提示；无需模型也可用规则实现，模型用于开放式措辞。**P0**。

#### A3 过滤规则自然语言生成
- **描述**："排除 node_modules、临时文件和大于 1GB 的文件" → 生成 `FileFilterOptions`（通配符/目录/大小/时间）。
- **价值**：过滤模板复用率低，主因是规则表达门槛。
- **落地**：同 A1，输出映射到 `FileFilterOptions` 并实时预览命中数。**P0**。

#### A4 对话式使用帮助（RAG）
- **描述**：基于本地 CHM/文档做检索增强问答，回答"镜像同步会不会删我文件？""双向冲突怎么处理？"。
- **价值**：替代翻阅 9 章手册，上下文相关。
- **落地**：对 `docs/help-src` 做本地向量化（或关键词检索），纯本地、无外部调用。
- **隐私**：完全本地。**P1**。

### B. 决策辅助（执行前/后）

#### B1 执行前风险解释（变更摘要）
- **描述**：把 `CopyPlan` 翻译成自然语言："将新增 3 个、覆盖 12 个、把 5 个移入隔离区，删除占比 8%，超过你设的 5% 阈值，已阻止。"
- **价值**：预览列表对非专业用户不友好，自然语言摘要 + 风险分级明显提升安全确认质量。
- **落地**：结构化数据 → 模板化 + LLM 润色（可降级为纯模板）。**P0**。

#### B2 冲突解决建议
- **描述**：双向同步出现"双方都改过"时，AI 结合文件名/大小/时间差/修改频率，建议保留哪份或建议打开内容比对，并解释理由。
- **价值**：双向冲突是高频痛点，逐项确认成本高。
- **落地**：元数据启发式打分 + LLM 措辞；不自动执行，仍走 `ConflictResolutionPolicy`。**P1**。

#### B3 失败根因分析与修复建议
- **描述**：聚合运行失败（复用迭代 12 的 `FailureAggregationService`），输出"某 NAS 路径反复权限不足，建议检查共享权限或改用映射盘"。
- **价值**：把"一堆错误"变成"一条可执行建议"。
- **落地**：分类结果 + 历史上下文喂给 LLM 生成建议；规则兜底。**P1**。

#### B4 智能重试/等待策略建议
- **描述**：根据失败类型（网络抖动 vs 权限 vs 空间）建议重试次数、退避间隔、是否等待设备可用。
- **价值**：现有 `RetryPolicy` 是全局配置，AI 可按失败类型给出更优参数。
- **落地**：建议值填入 `RetryPolicy` 候选，用户确认。**P2**。

### C. 数据理解（内容级，需授权）

#### C1 智能文件分类与标签
- **描述**：对文件/照片/文档按内容语义打标签（"证件照/发票/合同/代码"），辅助组织与过滤。
- **价值**：为过滤、归档、搜索提供语义维度，而不只是扩展名。
- **隐私**：**需读内容，必须显式授权**；本地模型优先。
- **落地**：内容嵌入 → 分类器；仅保存标签结果，不缓存原文。**P2**。

#### C2 重复/相似文件智能识别（升级版）
- **描述**：在现有 SHA-256 精确去重基础上，增加感知哈希（图片近似重复）、语义相似（文档/文本）识别。
- **价值**：精确去重漏掉"改尺寸的同一张图""略改的同一份文档"。
- **隐私**：需读内容，授权后本地处理。**P2**。

#### C3 敏感文件识别与防误同步
- **描述**：识别凭据、私钥、`.env`、身份证/银行卡影像、病历等，默认排除并提醒，避免把敏感数据同步到云盘/外部盘。
- **价值**：数据安全是产品核心承诺，AI 补上"内容敏感"这一层（现有只做凭据存储脱敏，不做文件内容识别）。
- **落地**：文件名/模式规则（无需模型）+ 可选内容模型；结果作为默认排除建议，不强制。**P1**。

#### C4 智能归档整理
- **描述**："把下载目录按类型/日期归档" → 生成移动计划（走隔离区语义），预览后执行。
- **价值**：从"复制/同步"延伸到"整理"，拓展产品场景。
- **隐私**：需读内容分类；移动仍走现有安全执行链。**P2**。

### D. 运维、预测与报告

#### D1 预测性空间管理
- **描述**：基于 `StorageTrendService` 的增长曲线，自然语言预警"按当前增速，E 盘约 42 天后满，建议清理 X 或扩容"。
- **价值**：把趋势数字变成可行动的提醒。
- **落地**：纯规则可算，LLM 只做措辞。**P1**。

#### D2 健康报告自然语言生成
- **描述**：把 `HealthScoreService` 的分数/隐患 + 失败聚合 + 备份新鲜度，生成月报/季报摘要。
- **价值**：面向"不看仪表盘"的用户，一封邮件看懂状态。
- **落地**：结构化指标 + 模板 + LLM 润色，随现有邮件/IM 通知发送。**P1**。

#### D3 智能调度优化
- **描述**：分析历史运行时长与失败时间窗，建议把长任务移到低峰、避开失败时段（结合迭代 12 的维护窗口）。
- **价值**：现有调度是固定时间，AI 可给出"何时跑最稳"的建议。
- **落地**：历史统计 + 建议写入 `TimeWindow`/计划，用户确认。**P2**。

#### D4 任务耗时预估
- **描述**：按历史同类任务的速率估算本次预计耗时（"约 8 分钟"），而非只看字节数。
- **价值**：提升可预期性，配合 `--dry-run` 与调度。
- **落地**：历史吞吐统计 + 线性外推，无需模型。**P2**。

### E. 安全增强

#### E1 异常行为检测升级
- **描述**：在迭代 12 的 `RansomwareChangeDetector`（阈值/时间窗）之上，用序列模型识别"渐进式加密/低频异常"，减少误报漏报。
- **价值**：勒索软件常规避简单阈值；异常检测是差异化安全能力。
- **落地**：本地模型或统计异常检测，输出告警不自动删停。**P2**。

#### E2 恢复演练结果解读
- **描述**：把 `RestoreDrillResult`（校验成功/失败项）转成"你的备份可恢复性 98%，失败项是 xxx，原因可能是 yyy"。
- **价值**：恢复演练报告太技术化，自然语言让非专业用户理解备份是否真的可靠。**P1**。

### F. 传输与效率

#### F1 传输策略智能建议
- **描述**：根据文件规模/网络类型/磁盘类型，建议是否启用块级增量（`TransferMode.Delta`）、压缩、并发数、分时段限速。
- **价值**：这些新能力（迭代 12）参数多，AI 帮用户选对组合。
- **落地**：基于 `PerformanceOptions`/`SpeedSchedule` 的规则 + 建议，用户确认。**P2**。

## 3. 建议落地路线（三阶段）

### 阶段一：元数据 + 规则，无内容外发（风险最低，立即可做）
- 目标：P0 全部 + D1/D2/E2（这些本质上都是"结构化数据 → 自然语言"，可用模板 + 轻量 LLM，甚至纯规则兜底）。
- 关键：`IAiAssistant` 抽象 + provider 降级；A1/A3 的 LLM 输出必须过 schema 校验再落到现有领域对象。
- 隐私：仅元数据、运行历史、错误信息，**不读文件内容**。

### 阶段二：授权的内容级理解（本地优先）
- 目标：C3 敏感识别（先做，安全价值高）→ C1/C2/C4。
- 关键：默认关闭，逐任务/逐目录授权；优先本地模型，绝不默认把内容上传云端。
- 隐私：明确告知"将读取文件内容用于 X"，结果仅存标签/哈希，不缓存原文。

### 阶段三：高级预测与异常（可选，按反馈）
- 目标：B2/B4、D3/D4、E1、F1。
- 关键：需要积累历史数据（运行时长、失败分布、存储增长）才有信号；模型以统计/本地小模型为主。

## 4. 需要明确的取舍与风险

1. **内容外发是红线**：任何读文件内容的 AI 能力都必须显式授权，并默认本地模型；云端只传元数据/摘要，绝不默认传文件正文。
2. **AI 不越过安全闭环**：删除、覆盖、隔离仍由现有阈值/竞态检查/预览确认把关；AI 建议一律需要用户确认后落入现有参数，而不是直接改配置执行。
3. **确定性回退**：每个 AI 能力都要有"无模型/无网络时"的规则版本，避免 AI 成为单点故障。
4. **成本与延迟**：生成式调用有延迟和成本，交互层（A1-A3、B1）用"异步 + 可取消 + 结果可编辑"的形态，不阻塞复制主流程。
5. **幻觉防护**：LLM 生成的任务配置/过滤规则必须结构化校验 + 预览，非法值拒绝并回退；建议类文案不进入任何执行路径。

## 6. 建议首个实现切片（MVP）

若只先做**一个**最小闭环，建议组合：

> **A1 自然语言任务创建 + B1 执行前风险解释**，共用 `IAiAssistant` 抽象与 provider 降级。

理由：它同时覆盖"降低上手门槛"（配置）与"守住安全底线"（执行前确认），是文件同步工具 AI 化最高性价比的切入点，且全程只用元数据、不触碰文件内容，隐私风险最低。
