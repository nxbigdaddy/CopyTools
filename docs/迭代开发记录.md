## 环境相关验证边界

下列功能代码和错误处理已完成，但端到端连接需要部署环境提供外部条件：

- MTP：需要实际手机或相机及 Windows Portable Devices 驱动。
- FTP/SFTP/WebDAV、对象存储和云盘：需要用户自己的服务、账号、令牌和网络访问。
- VSS：需要本地 NTFS 卷、VSS 服务及相应管理员权限；UNC 路径不使用 VSS。
- Windows Service 安装：需要管理员权限；普通开发验证使用 `--check`，不擅自写入系统服务注册表。

这些是环境验收项，不是代码功能缺口。后续迭代应以真实用户反馈、特定厂商 API 变化和规模压测为主，不再有功能清单中的未实现项。
