选择正确的复制与同步模式

模式行为适用场景风险提示
完整复制扫描并复制源端全部文件，按现有文件策略处理同名文件。第一次迁移、制作完整副本。数据量大；覆盖前应启用版本保留。
增量复制只复制目标端缺少或源端已更新的文件，不删除目标多余项。日常追加备份、移动硬盘归档。目标会保留源端已经删除的旧文件。
单向同步让目标跟随源端新增与修改；根据已保存快照处理记录过的删除。主目录向副本持续同步。需先保存任务，以便维护同步快照。
镜像同步让目标与源完全一致，包括删除目标端多余文件。构建可替换镜像、部署目录。会产生删除计划，必须重点检查预览。
双向同步依据上次成功快照判断两侧新增、修改、删除和冲突，并向双方传播。两台电脑轮流编辑同一资料集。双方同时修改同一文件会进入冲突处理。
移动同步目标写入且校验成功后，从源端移除相应文件。相机卡导入、收件目录搬运。源端会减少文件；重要数据应先做副本。
更新同步仅在目标已存在且源端较新时更新，不创建目标缺少的文件。只刷新既有部署文件。不会补齐目标中完全缺失的文件。

高级设置

过滤规则

包含和排除支持通配规则，可按扩展名、目录或相对路径筛选。排除规则优先于包含规则。建议生成预览后按“原因”列核对过滤效果。

同名文件策略

  • 按模式判断：比较大小、修改时间或同步快照。
  • 始终覆盖：强制用源文件替换目标，适合已知来源可信的发布目录。
  • 跳过：目标存在时不写入。
  • 保留版本：覆盖前把原文件保存到版本目录，可从“覆盖版本”恢复。

校验与重试

快速校验适合普通本地复制；SHA-256 会读取文件内容确认一致，适合归档和不稳定链路。失败项按设置次数和延迟自动重试，也可在底部执行栏单独重试。

性能控制

“自动调优”会根据任务和存储特征选择并发数；也可以设置缓冲区、最大并行文件和限速。机械硬盘随机读写时并发不宜过高；后台任务可在应用设置里使用独立限速。

镜像与移动模式：只有预览中明确列出的动作才会被执行。不要跳过预览；当删除数量或比例超过安全阈值时，CopyTools 会阻止执行并要求重新确认配置。
