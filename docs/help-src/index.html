欢迎使用 CopyTools

CopyTools 是面向 Windows 10/11 x64 的文件复制、目录同步、版本备份和自动执行工具。所有会写入目标目录的任务均可先生成预览，删除操作默认进入隔离区。

第一次使用：建议先阅读“五分钟快速上手”。选择源和目标后先单击“生成预览”，核对操作列表，再执行任务。

图 1：一体化标题栏、左侧工作区导航与复制任务编辑区

界面区域

区域用途
一体化标题栏显示产品名称、安全理念、帮助入口以及最小化、最大化和关闭按钮。按 F1 可随时打开本帮助。
左侧工作区切换复制任务、已保存任务、运行历史、隔离区、自动化、备份、远程存储、插件和设置等功能。
任务编辑区配置源路径、目标目录、复制模式、过滤规则、校验方式、重试和性能选项。
操作预览列出将执行的复制、更新、移动、删除和冲突处理动作；可排除单项后再运行。
底部执行栏显示进度和当前状态，并提供重试失败项、暂停、继续、取消与开始执行。

按目标查找帮助

  • 立即复制或同步一批文件：快速上手
  • 理解单向、双向、镜像、移动和更新模式：复制与同步模式
  • 创建时间点并选择性恢复文件：版本备份与恢复
  • 每天、每周、间隔或登录时自动执行：计划任务与实时触发
  • 连接 FTP、SFTP、WebDAV 或云存储：存储连接与传输
  • 了解预览、删除阈值、隔离区和恢复：安全与可恢复机制
  • 软件无法执行或连接失败：故障排查
