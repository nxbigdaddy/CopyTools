# CopyTools 1.1.0 界面与帮助验收报告

日期：2026-08-14

## 交付范围

- 一体化深色标题栏，内置帮助、最小化、最大化和关闭操作。
- 14 个功能工作区改为左侧垂直导航，保留滚动、状态记忆和键盘访问。
- 标题栏、侧边栏、托盘菜单和 `F1` 四个帮助入口。
- 9 章中文 CHM 使用手册、6 张真实界面截图、目录、索引和全文搜索。
- CHM 源文件和可重复构建脚本纳入仓库，发布过程自动生成并装入桌面端。

## 真实界面验证

- WPF Debug 构建：0 警告、0 错误。
- 原生窗口尺寸：1240×820；一体化标题栏和左侧导航完整显示。
- 逐页截图检查：复制任务、已保存任务、计划任务、版本备份与恢复、存储连接与传输、应用设置。
- Windows 桌面自动化可识别并切换 14 个工作区。
- `F1` 从运行中的 CopyTools 启动 Windows `hh.exe`。

- `hh.exe` 实机检查通过：窗口标题、中文正文、目录树、8 个子章节、章节跳转和页面内导航显示正确。
- 截图均为新版 CopyTools 的真实窗口捕获，分辨率为 1240×820。

- 色彩：深海军蓝标题栏、蓝色主操作、浅灰蓝页面、白色内容卡片。
- 结构：标题栏、任务中心、左侧工作区和右侧内容形成稳定层级。

- 功能没有因视觉改版删除；原 14 个工作区、底部执行栏和状态记忆全部保留。
