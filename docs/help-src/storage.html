支持的连接

CopyTools 可管理本地或可移动磁盘、MTP 手机/相机、UNC 共享、FTP/FTPS/SFTP、WebDAV、OneDrive、Google Drive、Dropbox、S3 兼容存储、阿里云 OSS、腾讯云 COS 和百度网盘连接。

新增和测试连接

  1. 单击“新增连接”，选择存储类型。
  2. 填写显示名称、端点或本地路径，以及可选根目录。
  3. 按连接类型填写账号、令牌、密钥或其他参数。敏感凭据进入 Windows 安全存储，不写入任务 JSON 和普通日志。
  4. 保存后先单击“测试连接”。测试成功不代表拥有所有写入或删除权限，第一次仍应使用一个小测试目录。

跨存储目录传输

  1. 在下方分别选择源连接和目标连接。
  2. 填写相对于连接根目录的源、目标路径；留空表示根目录。
  3. 选择是否允许覆盖目标同名文件。
  4. 先生成传输预览，核对文件数、总量和覆盖项，再执行。
问题检查重点
连接测试失败端点协议和端口、代理、系统时间、证书、账号权限、令牌有效期。
能列目录但不能上传远端写入权限、配额、对象键或 WebDAV 根路径。
大文件中断网络稳定性、服务端单文件限制、分片上传能力和重试设置。
文件名异常远端是否限制 Windows 保留字符、末尾空格、超长路径或大小写。
网络凭据只保存在 Windows 当前用户上下文。把任务导出到另一台电脑后，需要在新电脑重新创建或绑定连接凭据。
